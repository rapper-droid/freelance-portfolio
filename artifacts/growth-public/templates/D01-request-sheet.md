販売候補（ココナラ コンテンツマーケット等）。**未出品**。

## このシートの使い方

Web制作や修正を誰かに頼むとき、最初のメッセージに何を書けばよいかをまとめた
記入シートです。埋めてそのまま送れば、見積もりまでの往復が減ります。
専門用語は不要です。分かる範囲で構いません。

## 1. 今の状況

| 項目                 | 記入欄 | 記入例                                           |
| -------------------- | ------ | ------------------------------------------------ |
| 対象ページ           |        | https://example.com/price                        |
| 今どうなっているか   |        | スマホで料金表が右にはみ出して読めない           |
| いつから             |        | 先月サイトを更新したあと                         |
| 起きる端末・ブラウザ |        | iPhone Safari。PCでは問題なし                    |
| 再現手順             |        | ページを開いて下へスクロール、料金表で横にずれる |

## 2. どうなったら完了か

| 項目                 | 記入欄 | 記入例                                   |
| -------------------- | ------ | ---------------------------------------- |
| 完了の状態           |        | iPhoneで横スクロールなしに料金表が読める |
| 見た目の希望         |        | 今のデザインのまま。色や書体は変えない   |
| 触ってほしくない箇所 |        | 予約ボタンの位置とリンク先               |

## 3. 渡せるもの

- [ ] 対象ページのURL
- [ ] 崩れている画面のスクリーンショット
- [ ] ソースコード（HTML / CSS など）
- [ ] 管理画面の編集権限（※パスワードは最初のメッセージで送らない）
- [ ] デザインデータ（Figma / PSD など）
- [ ] 参考にしたいサイト

## 4. 条件

| 項目                 | 記入欄                                 |
| -------------------- | -------------------------------------- |
| 希望時期             |                                        |
| 予算の目安           |                                        |
| 連絡方法             | メッセージ中心 / 会議も可              |
| 公開作業を誰がやるか | 自分でできる / 依頼したい / 分からない |

## 5. 受け取り時の確認（検収チェック）

- [ ] 合意した画面幅・ブラウザで、直したい箇所が直っている
- [ ] 直した箇所以外の表示が変わっていない
- [ ] 修正前後のスクリーンショットをもらった
- [ ] 自分で確認する手順をもらった
- [ ] 納品ファイル（差分またはファイル一式）を受け取った
- [ ] 追加で必要になった作業と費用を、事前に説明された

## 6. 送る前のひとこと

このシートを埋めたら、そのまま本文に貼って送れます。
分からない欄は「分からない」と書いて構いません。そこが相談の出発点になります。

## 販売時に決めること（所長）

- 価格（ココナラは500円〜）。税・手数料込みの表示を確認する。
- 1ファイルにまとめる形式（PDF）。表は記入できる形に整える。
- サムネイル: 自分で組んだ文字と図のみ。AI生成イラストは使わない。
- 説明文に連絡先・URLを入れない（ココナラの規定）。
- コンテンツマーケットの販売実績は、受託の実績として表示しない。
