## このシートの使い方

CSVの整形を人に頼む、または自分で仕組みにするときに、決めておくべきことを
埋めるシートです。ここが決まっていないと、同じデータでも結果が変わります。

## 1. 入力のかたち

| 項目               | 記入欄 | 記入例                                 |
| ------------------ | ------ | -------------------------------------- |
| ファイルの出どころ |        | 会計ソフトからの書き出し               |
| 文字コード         |        | UTF-8 / Shift_JIS / 分からない         |
| 1行目              |        | 列名がある / ない                      |
| 列の名前と順番     |        | 注文ID, 顧客名, 商品, 金額, ステータス |
| 1回あたりの行数    |        | 200行くらい                            |
| 頻度               |        | 毎週月曜                               |

## 2. 保持すべき値（**ここが事故の起きやすい場所**）

| 項目               | 記入欄 | 注意                                                              |
| ------------------ | ------ | ----------------------------------------------------------------- |
| 先頭に0がある値    |        | 例: 商品コード 00123。数値にすると0が消える                       |
| 全角で入る値       |        | 例: 住所の番地。半角に変換してよいか決める                        |
| 数式に見える値     |        | 例: `=`, `+`, `-`, `@` で始まる値。表計算ソフトが計算式として扱う |
| 桁区切り・通貨記号 |        | 例: 「1,200」のカンマと「￥」を残すか、数値だけにするか           |
| 日付の形式         |        | 例: 2026/09/20 と 2026-09-20 を混ぜない                           |

## 3. 加工ルール（3つまでに絞ると失敗しにくい）

| #   | ルール           | 判定の条件                        |
| --- | ---------------- | --------------------------------- |
| 1   | 例: 重複行を削除 | 全列が一致する行 / 注文IDが同じ行 |
| 2   |                  |                                   |
| 3   |                  |                                   |

## 4. 出力のかたち

| 項目               | 記入欄                            |
| ------------------ | --------------------------------- |
| 列と並び順         |                                   |
| ファイル名の付け方 |                                   |
| 文字コード         | UTF-8（Excelで開く場合はBOMつき） |
| 元のファイル       | 上書きしない（別名で保存する）    |

## 5. NGケース（受け取ったら止めるべき入力）

- [ ] 列数が行によって違う
- [ ] 1行目に列名がない、または重複した列名がある
- [ ] 想定の文字コードと違う
- [ ] 行数・列数が上限を超えている（例: 10,000行・50列）
- [ ] 個人情報が含まれている（共有前に架空の値へ置き換える）

## 6. 検収チェック

- [ ] サンプルで、決めたルールどおりの結果になった
- [ ] 先頭の0・全角・日付の形式が、決めたとおりに保たれている
- [ ] `=` などで始まる値が、そのまま計算式として実行されない形で出力される
- [ ] 元のファイルが変更されていない
- [ ] 手順書のとおりに、自分（または担当者）が実行できた
- [ ] 失敗したときにどうするかが書かれている
