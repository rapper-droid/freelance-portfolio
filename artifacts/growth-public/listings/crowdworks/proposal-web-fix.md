## 差し込むときの注意

- 【…】は必ず募集文の言葉に置き換える。置き換えないまま送らない。
  （`npm run growth:lint` が `status: ready_for_owner` の原稿で検出する）
- 「24時間対応」「即日納品」「必ず」は書かない。納期は素材受領と範囲合意のあと。
- 金額に触れる場合は、公開中の定額「5,500円（税込）」とその範囲（対象1ページ・
  表示不具合1種類）をそのまま書く。範囲を超えるなら「着手前に別途お見積り」と伝え、
  その場で独自の金額を出さない。
- 募集が「調査してほしい」の場合は、調査と修正を分けて書く。原因が特定できない
  可能性にも触れる。
- 相手が Zoom や電話を必須にしている募集には応募しない（足切り条件）。

## 送る前の確認

1. 募集が現在も受付中か（締切・応募人数）。
2. 同じクライアントへの重複提案になっていないか。
3. 再委託・二次請けの可否が募集文と矛盾していないか。
4. 作業量と手数料を引いて、受けられる条件か。
