## タイトル案（全角30字前後）

スマホの表示崩れ、1ページ1か所から直します

## サービス内容

スマートフォンで文字がはみ出す、ボタンが押しにくい、画像がずれる。
サイト全体の作り直しではなく、気になっている表示の不具合を1か所から修正します。

対象は1ページ・事前に合意した不具合1種類です。原因を確認したうえで修正し、
修正前後のスクリーンショットと、どの画面幅・ブラウザで確認すればよいかの手順を
お渡しします。

**お渡しするもの**

- 対象1ページ・不具合1種類の修正
- 修正したファイル、または変更点が分かる差分
- 修正前・修正後のスクリーンショット（合意した画面幅）
- 確認手順（見る画面幅・ブラウザ・確認する箇所）

**含まないもの**

- サイト全体の改修、デザインの作り直し
- 原因が分からない本番障害の緊急対応・復旧のお約束
- ログイン・決済・会員機能の改修
- サーバー・ドメイン・メール設定の変更

**ご用意いただくもの**

- 対象ページのURL
- 崩れている画面のスクリーンショットと、起きる端末・ブラウザ
- 修正するソースコード（HTML / CSS など）または編集できる環境
- どう表示されれば完了かのイメージ

**進め方**

ご相談 → 内容と範囲の確認 → お見積り → 合意 → 修正 → 確認（検収）→ 納品。
やり取りはメッセージ中心で進められます。オンライン会議は必須ではありません。
納期は、ソースと再現情報を受け取り範囲に合意した時点でお伝えします。

**修正対応**

合意した範囲内の軽微な調整を1回。別の箇所の修正や仕様の変更は、追加の範囲として
先にご相談します。

**確認できる制作例**

同じ原稿の Before / After を切り替えて、読み順・余白・ボタンの違いを確認できる
比較ページを自主制作で公開しています（https://tsudowa.com/demos/improvement）。
掲載している企業・商品・データは架空です。

## よくある質問

**Q. どんなサイトでも対応できますか？**
HTML / CSS で組まれたページや、Next.js / React のページを主に対応します。
WordPress や Shopify はテーマの編集方法を確認してからお答えします。
対応できない場合は、その旨をお伝えします。

**Q. 原因が分からなくても相談できますか？**
はい。まず再現情報をいただき、原因の見当がつくかを確認します。調べた結果
1か所の修正に収まらない場合は、作業の前にお伝えします。

**Q. パスワードを渡す必要はありますか？**
最初のご相談では不要です。作業に必要なファイルの受け渡し方法は、合意後に
ご相談します。
