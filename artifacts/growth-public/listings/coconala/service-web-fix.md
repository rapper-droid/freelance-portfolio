## サービスタイトル案

スマホで崩れる表示を1ページ1か所から直します

## キャッチコピー案

サイト全部の作り直しではなく、気になっているその1か所だけ。

## サービス内容

スマートフォンで文字がはみ出す、ボタンが押しにくい、画像がずれる。
そんな「気になっているけれど、作り直すほどではない」表示の不具合を、
1ページ・1種類から修正します。

### お渡しするもの

- 対象1ページ・事前に合意した表示不具合1種類の修正
- 修正したファイル、または変更点が分かる差分
- 修正前・修正後のスクリーンショット（合意した画面幅）
- どの画面幅・ブラウザで何を確認すればよいかの手順

### 含まないもの

- サイト全体の改修、デザインの作り直し
- 原因が分からないサイト停止時の緊急復旧のお約束
- ログイン・決済・会員機能の改修
- サーバー・ドメイン・メール設定の変更

### ご用意いただくもの

- 崩れている画面のスクリーンショットと、起きる端末・ブラウザ
- 修正するソースコード（HTML / CSS など）、または編集できる環境
- どう表示されれば完了かのイメージ

### 進め方

ご相談 → 内容と範囲の確認 → お見積り → 合意 → 修正 → ご確認 → 納品。
やり取りはトークルームのメッセージで進められます。ビデオチャットは必須では
ありません。納期は、必要な情報を受け取り範囲に合意した時点でお伝えします。

### 修正について

合意した範囲内の軽微な調整を1回お受けします。別の箇所の修正や仕様の変更は、
追加の範囲として先にご相談します。

### 対応できる環境

HTML / CSS で組まれたページ、Next.js / React のページを主に対応します。
WordPress・Shopify は、テーマの編集方法を確認してからお答えします。
確認の結果お受けできない場合は、その旨をお伝えします。

### お願い

パスワード・APIキー・顧客情報は、最初のご相談では送らないでください。
作業に必要なファイルの受け渡し方法は、合意後にご相談します。
