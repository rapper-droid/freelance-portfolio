# 短尺素材の撮影指示（実画面の録画）

外部の有料サービスは使わない。既存の Playwright とローカルの画面録画で足りる。
音声なしで意味が通るように、字幕（投稿側のテキスト）で補う。

## 共通

- 解像度: 1080×1350（縦）または 1080×1080。実機のブラウザ幅は390pxで撮る。
- 画面に映してはいけないもの: メールアドレス、受付番号、他のタブ、ブックマーク、
  秘密情報、未公開ページ。
- 撮影前にブラウザのプロフィール表示・拡張機能アイコンを隠す。
- 操作はゆっくり。1カット3秒以上。

## 01 CSV整形（15秒）

1. `/demos/csv` を開く（2秒）
2. 「サンプルを試す」→ 125件が表示される（3秒）
3. チェックを確認（重複を除去／空白を整える）（2秒）
4. 「加工を実行」→ 98件・重複27件・変更セル数が出る（4秒）
5. 「CSV出力」→ ダウンロード（2秒）
6. 最後に「この処理を毎回のCSVで」のリンクを映す（2秒）

## 02 表示崩れ Before / After（10秒）

1. `/demos/improvement` を開く（2秒）
2. Before の画面をスクロール（3秒）
3. After に切り替え（2秒）
4. 同じ位置までスクロールして違いを見せる（3秒）

## 03 相談文メーカー（12秒）

1. `/rescue` を開く（2秒）
2. 「データ整理を減らしたい」を選ぶ → 候補メニューが出る（3秒）
3. 困っていることを1行入力（3秒）
4. 下の相談文が組み上がる様子（4秒）

## 撮り方

```bash
# 画面幅を固定して開く（録画はOSの画面収録で行う）
npm run start -- --hostname 127.0.0.1 --port 3210
# 別ターミナル
npx playwright open --viewport-size=390,844 http://127.0.0.1:3210/demos/csv
```

書き出しは既存の ffmpeg があればローカルで軽く整える（なければ無加工で可）。
新しい有料の動画APIは使わない。
