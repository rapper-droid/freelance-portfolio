## 3. 公開の判断ルール（実装で守っていること）

- `state !== "verified"` の商品は、ページも sitemap もリンクも生成されない。
- 価格は `reference`（既存公開値）か `quote_required` のみ。数字を含む新しい
  価格文字列はユニットテストで弾く（`tests/unit/growth-offers.test.ts`）。
- 「必ず」「保証します」「即納」「24時間対応」「AIが分析」等の語は、商品データに
  入っていないことをテストで確認している。
- 納期は「範囲に合意した時点で提示」。暦上の即日・24時間納品を約束しない。

## 4. 所長に決めてほしいこと

1. W01・W02 を定額（5,500円 / 16,500円）で出すか、現在の「参考料金／見積」のままにするか。
2. 定額にする場合の税表示（内税・外税）と、案件サイト経由のときの手数料の扱い。
3. W03 を公開するか（このサイトの受付が実証になるが、顧客側の契約が絡む）。
4. 同時進行の上限（内部提案値: 小規模2件まで）。これを超える相談は待機扱いにする。
