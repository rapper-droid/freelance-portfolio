# 営業での使い方

## 共通応募文の骨子

募集内容を拝見しました。Web制作・業務ツールの設計から実装、動作確認、ソースと手順書の整理まで対応範囲をご相談できます。

関連する自主制作の例はこちらです。
【公開オリジン + 該当カテゴリのURL】

作品詳細に想定依頼、実装した機能、参考料金・期間、納品物を記載しています。デモには実案件の顧客情報や成果実績を含みません。

募集内容と必要な素材を確認し、制作範囲・納期・費用をご提示します。進行は本サービスのメッセージで可能です。

※ 実際の募集要件・応募条件に合わせて冒頭と対応範囲を確認してください。

## 送るURLの選び方

- LPの募集 → /works/lp
- 店舗・企業サイト → /works/web
- AI・自動化 → /works/automation（現在のデモはルールベースと明記）
- アプリ・予約・管理 → /works/apps
- 修正・スマホ対応 → /works/improvement または /works/responsive
- テスト・README・納品整理 → /works/qa

## 独自ドメイン案

候補文字列として `tetsu-works.jp`、`tetsu-build.com`、`build-with-tetsu.com`。空き状況・商標・登録価格は未確認。取得前に登録事業者で確認してください。どの候補もコードへ固定していません。

## 次に追加すると強い制作例

- 認証・権限・共有DBまで含む予約システム（架空データで公開）
- 許可されたテスト環境での決済連携と障害時の復旧
- 実AIモデル接続、費用上限、人の承認、評価データを備えた自動化
- 提供デザインからの忠実な実装と変更点レポート

実案件になった場合も、クライアントから公開許可を得た範囲だけ掲載します。
