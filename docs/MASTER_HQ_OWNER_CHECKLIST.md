# TSUDOWA HQ — OWNER REVIEW checklist

これはOWNERが実画面を見て記入するチェックリストです。
自動テストPASSは主観的なブランド承認や営業成果の保証ではありません。

- [ ] First impression — 3〜5秒でTSUDOWA全体の入口と分かる。
- [ ] Premium feel — 見た目の強さと落ち着きが両立している。
- [ ] Realism of imagery — 自主制作・架空写真と分かったうえで、画面や素材に説得力がある。
- [ ] Typography — 日本語、3行の英語、改行、文字間、本文の読みやすさ。
- [ ] Spacing — スマホから大画面まで余白と密度に不自然さがない。
- [ ] Motion quality — 初回演出、hover、遷移が内容を邪魔しない。
- [ ] CTA clarity — 制作依頼とLAB入口、制作相談と総合連絡の選択が明確。
- [ ] TSUDOWA → TETSU WORKS hierarchy — 親ブランドと制作窓口の役割が別々に伝わる。
- [ ] TSUKUTTA LAB — 独立ブランドへの興味を持てる。公開先確認前のgatewayであることが誤解されない。
- [ ] Mobile quality — 390pxの最初の画面、2つの入口、MENU、本文、フォーム。
- [ ] 「依頼したいと思えるか」 — 制作能力と責任の所在が伝わる。
- [ ] 「また見に来たいか」 — 作品と制作記録の継続を見る理由がある。

## 公開前の別gate

- [ ] LAB本体の正式な公開先を確認する。
- [ ] 所有者がこのHQとgeneral contactの文面を承認する。
- [ ] 必要なら承認済み環境で、総合窓口のowner通知と確認メールの実配送を確認する。
- [ ] 実機iOS/Androidと実スクリーンリーダーで確認する。
- [ ] 公開する時点で性能・公開環境変数・contact設定を再検証する。
- [ ] push / merge / deployはこのUnitとは別に明示承認する。
