**実AI処理は 1 度も動いていない。** `ANTHROPIC_API_KEY` がこの環境に存在しないため。
**外部送信・カレンダー登録も 1 度も動いていない。** 接続先も送信許可も無いため。

この 2 つは画面上でも「未稼働」と表示される。表示は `modeNotice()` が環境変数から
生成するので、鍵を設定すれば文言も自動で変わる（手で書き換える箇所がない）。

## 実装したが稼働していないもの

| 能力                     | 実装場所                         | 稼働しない理由                                         |
| ------------------------ | -------------------------------- | ------------------------------------------------------ |
| 実AIによる抽出           | `runtime/extract/ai.ts`          | `ANTHROPIC_API_KEY` が無い。**代替でAI成功を装わない** |
| 永続ジョブ（再開・復元） | `runtime/store.ts`               | 公開サンプルは保存しない設計。実運用経路が未接続       |
| 外部送信・カレンダー登録 | `runtime/gateway.ts`             | 接続先が無く、`authoriseAction` が実行不可と判定する   |
| 実原価の記録             | `runtime/budget.ts` `costRecord` | 課金呼び出しが 0 件のため記録対象が無い                |

「鍵が無いのでルール処理に切り替えてAI成功と表示する」という経路は**存在しない**。
`selectExtractor` は AI を求められて使えないとき例外を投げる（単体テストで固定）。

## 公開サンプルが保存しないもの

`/api/flow` は受け取った本文を処理して同じリクエストで返す。
保存も転送もしない。したがって、

- 見知らぬ訪問者が入力した文章の台帳は存在しない。
- 外部 AI へ送る経路が無いので、同意取得の対象になる送信も発生しない。
- PostHog へは件数イベントのみ（`scenario_started` 等）。本文・ファイル名は送らない。

## 3 段階の位置づけ（指示書 §06）

- **PUBLIC SAMPLE** — 現在ここ。架空データ、登録不要、外部操作なし。
- **PRIVATE PILOT** — 未着手。所有者の許可済み入力とテスト領域で、実AIと
  実出力を検証する段階。必要な認証は `CONNECTOR_SETUP.md` に列挙した。
- **CUSTOMER LIVE** — 未着手。権限・同意・費用・障害時対応が確定した顧客環境。

公開サンプルをそのまま不特定多数向けの共有業務 SaaS へ切り替える設計にはしていない。
