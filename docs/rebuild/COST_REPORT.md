## 実AIを稼働させたときに発生するもの

**現時点で単価を書かない。** モデル価格と為替は変わるため、本書の固定値を
前提にすると誤った数字が残る。契約に基づき、実測で記録する。

測定の仕組みは実装済み（`runtime/budget.ts` の `costRecord()`）。
記録する項目は次のとおりで、単価は所有者が設定する。

- 呼び出し時点のモデル名（`claude-sonnet-5` を既定とし、変更時は記録が変わる）
- 入力・出力トークン数（プロバイダーの応答から取得）
- run ID / tenant / 時刻

## 実装済みの上限（指示書 §20）

| 単位         |     既定値 | 超過時の挙動                             |
| ------------ | ---------: | ---------------------------------------- |
| 1 run あたり |       4 回 | `BUDGET_EXHAUSTED` を返して停止          |
| 1 日         |     200 回 | 同上                                     |
| 1 か月       |   2,000 回 | 同上                                     |
| 入力長       | 4,000 文字 | 超過分は切り捨て、**切り捨てた旨を警告** |
| 再試行       |       2 回 | 指数バックオフ、以降は停止               |

いずれも `DEFAULT_LIMITS` で定義し、単体テストで挙動を固定している。
上限に達したときは正直に `BUDGET_EXHAUSTED` / `RATE_LIMITED` を表示し、
無限リトライしない。緊急停止（`RUNTIME_KILL_SWITCH`）は上限より先に効く。

カウンタが読めないときは「上限内」とみなさず保留する
（読めない＝使ってよい、にしない）。
